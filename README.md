# Oscheius_PDE: Genomics Research Project

## Overview
This repository contains the data, code, and analysis for programmed DNA elimination genomics research on *Oscheius* nematodes. The project utilises R for data processing and analysis of genomic data.

## Directory Structure
- `data/`: Contains all data files
  - `raw/`: Raw, unprocessed data files
  - `processed/`: Processed data ready for analysis
- `R/`: R functions and utilities
- `analysis/`: R scripts for data analysis
- `results/`: Output from analyses
- `figures/`: Plots and visualizations
- `tests/`: Unit tests for R functions

## Requirements
This project uses renv for package management to ensure reproducibility.

## Getting Started
1. Clone this repository
2. Open the R project file in RStudio
3. Run `renv::restore()` to install required packages
