# Oscheius PDE Manuscript Data & Scripts

This repository contains the data and scripts to reproduce all figures and tables for the manuscript **"Programmed DNA elimination in *Oscheius* nematodes"**.

## Requirements

The project uses [`renv`](https://rstudio.github.io/renv/articles/renv.html) to isolate package dependencies and ensure reproducibility.

To initialize the environment:
```r
# Launch R inside this directory and run:
renv::restore()
```

## Running the Pipeline

You can reproduce all analysis outputs by executing the master script from the terminal:

```bash
Rscript run_all.R
```

This will automatically execute the numbered scripts in the `analysis/` directory in sequence.

## Outputs

- **Main Figures:** Saved in `figures/main/` (PDF and PNG)
- **Supplementary Figures:** Saved in `figures/supplementary/` (PDF and PNG)
- **Tables:** Saved in `results/tables/` (TSV)

*Note: Figure S3 (PCR gel images) relies on manual microscopy outputs and is not dynamically generated by this pipeline.*
